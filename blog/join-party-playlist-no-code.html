How Guests Can Join a Party Playlist With No Code

Updated August 2026 · 3 min read

Reading out a code to a room full of people is a buzzkill. The best party apps let guests just… join. Here's how "nearby joining" works — a feature unique to Jukebox.

The short answer

With Jukebox, guests can join a party session just by being nearby the host — no code, no QR, no typing. It uses a short-range Bluetooth signal so nearby phones see the session and join with a single tap. A 6-digit code and QR code are there too, if you want them.

Three ways to join

  • Be nearby (no code) — the easiest. Guests near the host see the session in Jukebox and tap to join. No one has to read anything out.
  • Scan a QR code — put it on a screen or a table tent; guests point their camera and they're in.
  • Enter a 6-digit code — the classic fallback, handy for a big room.

Why "nearby" is better for a party

Codes and QR still require a step: find the code, type it, or open a camera. Nearby joining removes the step entirely — guests open the app and they're in. And because it uses a short-range signal, only people physically at the party can join. Someone across town can't crash your queue.

Is it private and safe?

Yes. The nearby signal only reaches people in the same room, and the host stays in control of the session — you can see who's in and remove anyone. Hosts can also require a PIN or limit joining by location if they want extra control.

Frequently asked questions

Can guests join a party playlist without a code?

Yes. In Jukebox, guests can join just by being nearby the host — no code, no QR, no typing. A 6-digit code and QR are also available.

How does joining by being nearby work?

The host's phone broadcasts the session over short-range Bluetooth. Nearby guests see it in Jukebox and tap to join. It only reaches people at the party, so randoms can't join.

Do guests need to download the app or make an account?

Guests use the free Jukebox app to join and vote, but need no account and no music subscription. Only the host needs Apple Music.
